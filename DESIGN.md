# Sistema de Diseño — Registro Clínico

## Paleta de Colores
- **Canvas principal**: `#F6F7F5` (blanco cálido suave, descansa la vista en jornadas largas)
- **Superficie / Tarjetas**: `#FFFFFF` con borde `#E2E8F0`
- **Sidebar (Navegación)**: Gradiente `#132A2E` → `#0D1F22` (pizarra clínica profunda)
- **Acento Sidebar Activo**: `#2DD4BF` (borde izquierdo) + `rgba(255,255,255,0.12)`
- **Primario (Acción principal)**: `#2A72DE` (hover `#1D5EC2`)
- **Éxito / Salud**: `#0F766E` / `#10B981`
- **Texto principal**: `#0F172A`
- **Texto secundario**: `#64748B`
- **Alerta / Error**: `#DC2626` (fondo suave `#FEF2F2`)

## Tipografía
- **Familia**: `"Segoe UI Variable", "Segoe UI", "Inter", sans-serif`
- **Títulos de vista**: `16px–18px`, `font-weight: 700`, `#0F172A`
- **Subtítulos / Etiquetas**: `12px–13px`, `#64748B`
- **Campos e inputs**: `13.5px`, radio `8px`, borde `1.5px solid #CBD5E1`

## Iconografía
- Iconos vectoriales SVG (`ui/widgets/app_icons.py`) estilo trazo fino (`1.75px`), renderizados con `QSvgRenderer`.
